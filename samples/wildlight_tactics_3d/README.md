# Wildlight Tactics — 3D Turn-based tactics Starter Kit

A hex-arena tactics scaffold with squad units, cover props, turn-state UI and camera markers. The sample includes reusable model and material sources to extend into a complete campaign.

## Included source
- `project.prism.json`: offline Android APK target and entry points.
- `scenes/main.scene.json`: editable hierarchy, transforms, and component metadata.
- `scripts/main.prism`: gameplay starter for the native PrismScript interpreter.
- `assets/models/*.obj`: editable source mesh geometry.
- `assets/textures/*.svg`: editable scalable source textures.
- `assets/materials/*.material.json`: PBR/spectral material settings and texture links.
- `ui/main.ui.json`: responsive HUD component/layout source.
- `controls/touch.json`: landscape virtual controls and actions.

These are working starter projects and source kits, not finished commercial games; native scene import, model/texture import, and standalone per-project APK export are still being integrated. All included assets are original procedural source files and work offline.
